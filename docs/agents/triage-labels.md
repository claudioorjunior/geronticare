# Triage Labels

Os skills falam em cinco papéis canônicos de triage. Este arquivo mapeia esses papéis para as strings de label usadas no issue tracker deste repo.

| Label no mattpocock/skills | Label no nosso tracker | Significado                                    |
| -------------------------- | ---------------------- | ---------------------------------------------- |
| `needs-triage`             | `needs-triage`         | Mantenedor precisa avaliar esta issue          |
| `needs-info`               | `needs-info`           | Aguardando mais informações do reporter        |
| `ready-for-agent`          | `ready-for-agent`      | Totalmente especificada, pronta para agente AFK |
| `ready-for-human`          | `ready-for-human`      | Requer implementação humana                    |
| `wontfix`                  | `wontfix`              | Não será executada                             |

Quando um skill menciona um papel (ex: "aplicar o label de triage AFK-ready"), use a string de label correspondente desta tabela.

Edite a coluna da direita para adequar ao vocabulário que você realmente usa.
