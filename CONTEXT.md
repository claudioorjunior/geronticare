# GerontiCare

## Language

**Aplicação de instrumento**:
Registro imutável de uma aplicação individual de uma escala a uma pessoa idosa.
_Avoid_: AGA, avaliação completa

**Instrumento**:
Escala ou protocolo clínico aplicado para avaliar um domínio específico.
_Avoid_: avaliação, formulário

**AGA**:
Consolidação clínica dos resultados de aplicações de instrumentos selecionadas para uma pessoa idosa.
_Avoid_: instrumento, formulário monolítico

**Consolidação**:
Ato de reunir aplicações previamente registradas para produzir uma visão integrada.
_Avoid_: aplicação, preenchimento

**Profissional aplicador**:
Profissional responsável por aplicar e interpretar diretamente um instrumento.
_Avoid_: usuário registrador

**Usuário registrador**:
Usuário autenticado que registra a aplicação no sistema.
_Avoid_: profissional aplicador
